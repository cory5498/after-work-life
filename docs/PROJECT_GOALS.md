# 專案目標與待確認事項

## 目標

建立一款名為 **《下班要做什麼?》** 的原創 Web 社交生活模擬遊戲。玩家經營一座社區，新增居民、觀察居民下班後的生活，並透過互動讓居民產生關係、心情變化與日常故事。

需求調查來源：

- Nintendo Store HK：https://store.nintendo.com.hk/70010000116666
- PChome 商品頁：https://24h.pchome.com.tw/prod/DGBJCW-A900JUCA1

參考遊戲已確認為 **《Tomodachi Life 朋友收集 夢想生活》中文版**。本專案只參考其抽象玩法類型，不複製 Nintendo、Mii、原遊戲素材或具體內容。

## 目前已知

- 遊戲類型：社交生活模擬、居民觀察、輕經營。
- 遊戲名稱：下班要做什麼?
- 核心樂趣：看居民依個性與關係自動產生日常互動，形成意外、有趣、貼近現實又可分享的故事。
- 玩家角色：人際觀察者 + 半個月老，可以觀察，也能有限介入。
- 遊戲目標：讓居民下班後的生活更豐富，累積關係、事件、回憶、社區活躍度與事件收集率。
- 主要操作：點選居民、查看狀態、回應需求、贈送物品、安排互動、布置區域。
- 平台目標：手機瀏覽器優先，桌面瀏覽器同步支援。
- 操作模式：手機橫向、單指點選為主，不依賴 hover、右鍵、精準拖曳或快速按鍵反應。
- 美術風格：像素風。
- 居民設定：玩家可依角色背景決定住處與人生起點，例如含著金湯匙、背債務、普通上班族、月光族、家裡有房。
- 關係方向：貼近現實生活，可包含友情、曖昧、交往、分手、前任、三角關係、第三者、多人追求與后宮式關係網。
- 內容尺度：15+，不做露骨描寫。
- MVP 關係：暗戀、曖昧、交往、分手、前任、第三者傳聞。
- 長期目標：社區活躍度 + 事件收集率，八卦熱度作為副指標。
- 技術方向：前端單機優先，本機存檔。

## 不做的事

- 不做 Tomodachi Life 的直接網頁移植。
- 不使用 Mii、Nintendo 商標、原遊戲 UI、截圖、音效、音樂或角色。
- MVP 不做多人連線、帳號系統、商城、排行榜。
- MVP 不做複雜 3D 角色編輯器。

## 原創方向

原創題材調整為「下班後的社區日常模擬」。遊戲名稱已定為 **《下班要做什麼?》**，需避開原遊戲名稱與商標。

可行主題：

- 下班生活圈。
- 住宅區。
- 便利商店。
- 餐酒館。
- 公園或河堤。
- 捷運口或公車站。

MVP 採用 **下班生活圈**，包含住宅區、便利商店、餐酒館、公園或河堤、捷運口或公車站。住宅區不固定單一類型，而是根據居民設定決定，例如社區大樓、出租套房、老公寓、住商混合大樓、家裡提供的房子或臨時借住。

## 待實作前確認

正式開發前，仍建議確認以下項目：

1. 像素居民要偏可愛，還是偏上班族日常？
2. 玩家是否可以在 MVP 自訂居民姓名、個性、人生背景與住處，或先使用預設居民？
3. 事件文字要偏日常幽默、荒誕八卦、成人諷刺，還是療癒觀察？
4. MVP 是否需要真實時間，例如早中晚、每日事件？
5. 本機存檔是否足夠，或未來需要雲端帳號？

## 成功標準

第一階段成功標準：

- 玩家能建立或選擇居民。
- 居民會依心情、需求與關係產生事件。
- 玩家能透過行動影響事件結果。
- 遊戲會保存居民與社區狀態。
- 玩家可以只用手機單指完成主要流程。
- 新玩家不用讀長篇說明也能理解：「這是一個會自己產生故事的社區」。
