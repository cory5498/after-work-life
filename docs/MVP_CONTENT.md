# MVP 內容規格

## 決策摘要

- 內容尺度：15+。
- 描寫邊界：可有第三者、劈腿疑雲、前任修羅場、多人追求，但不做露骨描寫。
- 玩家角色：人際觀察者 + 半個月老。
- MVP 關係：暗戀、曖昧、交往、分手、前任、第三者傳聞。
- 後續關係：后宮式關係網。
- 人生背景：影響事件條件、事件文字、心情與金錢壓力，不做完整經濟系統。
- 長期目標：社區活躍度 + 事件收集率。
- 副指標：八卦熱度。

## Enum 草案

### `lifeBackground`

- `golden_spoon`：含著金湯匙。
- `in_debt`：背債務。
- `salary_worker`：普通上班族。
- `paycheck_to_paycheck`：月光族。
- `family_property`：家裡有房。
- `out_of_towner`：外地打拚。

### `housingType`

- `apartment_complex`：社區大樓。
- `rental_studio`：出租套房。
- `old_walkup`：老公寓。
- `mixed_use_building`：住商混合大樓。
- `family_owned_home`：家裡提供的房子。
- `temporary_stay`：臨時借住。

### `financeState`

- `comfortable`：寬裕。
- `stable`：穩定。
- `tight`：吃緊。
- `debt_pressure`：債務壓力。
- `payday_waiting`：等發薪。

### `relationshipTag`

- `stranger`：陌生。
- `acquaintance`：認識。
- `friend`：朋友。
- `close_friend`：好朋友。
- `crush`：暗戀。
- `ambiguous`：曖昧。
- `dating`：交往中。
- `ex`：前任。
- `awkward`：尷尬。
- `conflict`：爭執中。
- `third_party_rumor`：第三者傳聞。

## UI 草圖

手機橫向 MVP：

```text
┌──────────┬──────────────────────────────┬──────────────┐
│ 側邊導覽 │ 像素風下班生活圈地圖         │ 事件/詳情面板 │
│ 社區     │ 住宅區  便利商店  餐酒館     │ 當前事件      │
│ 居民     │ 公園/河堤   捷運口/公車站    │ 選項按鈕      │
│ 事件     │ 居民小人 + 表情泡泡          │ 狀態變化      │
│ 物品     │                              │              │
│ 設定     │                              │              │
└──────────┴──────────────────────────────┴──────────────┘
```

主要規則：

- 側邊導覽固定在左側或右側。
- 中央地圖區域是主要視覺焦點。
- 事件面板可固定在另一側，也可在小螢幕改成覆蓋面板。
- 每個可點選區域至少 44px x 44px。
- 地圖區域不依賴 hover。
- 直向手機顯示旋轉提示或簡化版面。
