# 美術方向

## 目前狀態

美術方向已確認 MVP 採用 **像素風**。遊戲名稱已定為 **《下班要做什麼?》**，題材更偏都市、下班後、人際關係與生活 drama，因此像素風需要避免過度童趣，改走成人下班生活圈、夜晚街區、八卦事件與關係網的方向。

## 非 MVP 備選風格

以下風格已評估，但目前不作為 MVP 主要方向。

### 方案 A：都會漫畫風

特色：

- 2D 半身角色。
- 線條乾淨，表情誇張。
- 顏色明亮但帶一點都會感。
- 適合表現八卦、曖昧、修羅場、下班疲憊。

優點：

- 最符合「下班要做什麼?」。
- 角色表情和事件文字可以互相加分。
- 比較容易做成社群分享圖。

風險：

- 角色立繪需要較多素材。

### 方案 B：社群貼圖風

特色：

- 大頭角色。
- 表情符號化。
- 動作簡單，情緒強烈。
- UI 可以像聊天、社群動態或八卦牆。

優點：

- 適合手機橫向。
- MVP 可以先用少量頭像和表情完成。
- 很適合人際 drama。

風險：

- 若太可愛，可能會削弱現實關係的尖銳感。

### 方案 C：像素風公寓

特色：

- 小比例像素角色。
- 橫向社區、公寓或商店街地圖。
- 居民像在小舞台上移動。

優點：

- 容易做橫向手機畫面。
- 素材量可控。
- 有遊戲感。

風險：

- 情緒與曖昧細節較難只靠角色表現，需要文字補強。

### 方案 D：低多邊形插畫風

特色：

- 幾何人物。
- 色塊建築和場景。
- 更偏設計感與輕鬆經營。

優點：

- 原創性高。
- 容易避開既有遊戲視覺。

風險：

- 人際 drama 的表情張力較弱。

## MVP 決策

MVP 採用 **方案 C：像素風公寓 / 像素風生活圈**。

原因：

- 適合手機橫向地圖。
- 場景可以做成可點選的橫向生活圈。
- 居民可以用小比例角色在公寓、便利商店、餐酒館、公園、捷運口之間活動。
- 素材量可控，適合 MVP。
- 情緒與 drama 可透過事件卡片、表情泡泡、關係標籤補強。

MVP 美術組成：

- 像素居民：小比例成人角色，透過髮型、衣著、配色、表情泡泡區分個性與背景。
- 像素生活圈地圖：住宅區、便利商店、餐酒館、公園或河堤、捷運口或公車站。
- 事件卡片：像聊天訊息、社群貼文或八卦通知，但外觀需配合像素 UI。
- 關係視覺：像素線條、標籤、熱度、信任度、尷尬度。
- 人生背景提示：用小圖示或住處外觀提示含著金湯匙、背債務、月光族、外地打拚等狀態。

## 像素風規格

MVP 建議：

- 視角：2D 橫向側視或輕微俯視，不做 3D。
- 地圖：一張橫向生活圈，可左右延伸。
- 角色：小比例像素角色，避免做成兒童感，服裝以成人上班族、休閒下班服為主。
- UI：像素邊框、清楚按鈕、事件卡片和關係標籤。
- 動畫：MVP 只做待機、走路、表情泡泡、事件提示。
- 色彩：夜晚下班氛圍，便利商店和餐酒館用暖光，背景用城市暗色與招牌色點綴。

像素風的限制：

- 角色表情細節不足，需要事件文字與狀態標籤補強。
- 關係 drama 不能只靠角色演出，需要關係圖、事件紀錄與通知。
- 手機橫向畫面要避免角色太小，主要可點擊區域仍需符合觸控尺寸。

## 主場景決策

### 下班生活圈

主場景採用 **下班生活圈**，不是單一共享公寓。它包含住處、商店街、餐酒館、公園或河堤、捷運口或公車站，讓居民在下班後自然移動、偶遇、曖昧、吵架、和解。

組成：

- 住宅區：社區大樓、出租套房、老公寓或住商混合大樓，用來承載鄰居關係、前任住附近、深夜拜訪、曖昧串門。
- 便利商店：偶遇、買宵夜、撞見曖昧對象。
- 餐酒館：下班聚會、喝一杯、三角關係、前任修羅場。
- 公園或河堤：談心、告白、分手、冷靜。
- 捷運口或公車站：偶遇、錯過、跟誰一起回家。

優點：

- 最貼合「下班要做什麼?」。
- 能自然產生友情、曖昧、第三者、后宮式關係網。
- 適合手機橫向地圖。
- 場景可逐步解鎖，不需要一開始做很大。

### 為什麼不用「共享公寓」當主設定

共享公寓可以作為其中一種住處，但不應該成為整個遊戲的主設定。它在現實中不是所有玩家都熟悉，而且會把居民關係限制在同住者之間。

更好的做法是用 **住宅區** 作為通用概念，並讓住處根據居民的人生背景變化：

- 社區大樓：最現代、最泛用。
- 出租套房：適合年輕上班族。
- 老公寓：適合鄰居八卦與生活感。
- 住商混合大樓：樓下就是店、餐酒館或便利商店，很適合橫向地圖。
- 家裡提供的房子：適合含著金湯匙、家庭干涉、價值觀衝突。
- 臨時借住：適合背債務、分手後搬家、友情壓力。

### 可擴充區域：都市公寓

適合做鄰里關係與室內生活。

優點：

- 系統單純。
- 居民互動集中。
- 容易做 MVP。

風險：

- 場景變化較少，容易變成純居民列表。

### 可擴充區域：辦公室附近生活圈

適合下班後同事、主管、前同事、客戶之間的社交 drama。

優點：

- 很貼近成人現實生活。
- 容易寫出八卦和曖昧事件。

風險：

- 可能太偏職場，需要避免變成辦公室模擬。

### 可擴充區域：海邊社區

適合療癒與慢生活。

優點：

- 氣氛舒服。
- 視覺辨識度高。

風險：

- 和「下班」主題距離較遠，人際 drama 的現實感較弱。
