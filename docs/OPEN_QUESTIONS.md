# 待確認事項

## 已確認

- 遊戲名稱：下班要做什麼?
- 平台：Web。
- 手機版：橫向為主要設計基準。
- 操作：手機單指點選，桌面滑鼠與鍵盤補充。
- 類型：社交生活模擬。
- 美術風格：像素風。
- 內容尺度：15+，可有第三者、劈腿疑雲、前任修羅場、多人追求，但不做露骨描寫。
- MVP 關係系統：暗戀、曖昧、交往、分手、前任、第三者傳聞。
- 后宮式關係網：後續擴充。
- 人生背景深度：影響事件條件、事件文字、心情與金錢壓力，不做完整經濟系統。
- 玩家角色：人際觀察者 + 半個月老。
- 長期目標：社區活躍度 + 事件收集率，八卦熱度作為副指標。
- 主場景：下班生活圈，包含住宅區、便利商店、餐酒館、公園或河堤、捷運口或公車站。
- 住宅區：不固定單一類型，依居民設定變化。
- 居民背景：可包含含著金湯匙、背債務、普通上班族、月光族、家裡有房等人生起點。
- 關係方向：貼近現實生活，可包含第三者、多人追求、后宮式關係網等 drama。

## 已收斂決策

1. 內容尺度與分級

MVP 定為 15+，角色預設全部成年，事件不做露骨性描寫。

2. 關係系統深度

MVP 先做暗戀、曖昧、交往、分手、前任、第三者傳聞。后宮式關係網後續擴充。

3. 人生背景深度

MVP 先讓人生背景影響事件條件、事件文字、心情與金錢壓力。

4. 玩家角色

玩家是人際觀察者 + 半個月老，可以觀察，也能有限介入。

5. 勝利與目標

主指標是社區活躍度 + 事件收集率。八卦熱度是副指標。

6. 初始居民

已在 [MVP 內容規格](MVP_CONTENT.md) 定義 5 位初始居民。

7. 技術實作方式

直接以 Vite + TypeScript、localStorage、橫向手機 UI、DOM + CSS 像素風地圖開始。
