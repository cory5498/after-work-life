# 下班要做什麼?

此專案目標是建立一款可在瀏覽器中遊玩的原創社交生活模擬遊戲，遊戲名稱為 **《下班要做什麼?》**。需求調查參考：

- Nintendo Store HK：https://store.nintendo.com.hk/70010000116666
- PChome 商品頁：https://24h.pchome.com.tw/prod/DGBJCW-A900JUCA1

目前已確認參考遊戲方向為 **Nintendo Switch《Tomodachi Life 朋友收集 夢想生活》中文版**。它的核心不是動作闖關或傳統 RPG，而是讓玩家建立居民、觀察居民生活、介入人際事件，並經營一個會自己產生故事的生活圈。

本專案不複製 Nintendo、Mii 或原遊戲的角色、美術、音效、UI、名稱與世界觀，而是以第一性原則拆解出「居民生活模擬」的抽象玩法，重新做成原創 Web 遊戲。

## 核心玩法

玩家經營一座原創社區，新增居民、觀察居民互動，並回應他們下班後的人際、生活與情感需求。

MVP 主場景是 **下班生活圈**，包含住宅區、便利商店、餐酒館、公園或河堤、捷運口或公車站。住宅區不限定共享公寓，可用社區大樓、出租套房、老公寓或住商混合大樓呈現。

居民可依玩家設定擁有不同人生背景與住處，例如含著金湯匙、背債務、普通上班族、月光族、家裡有房、外地打拚。這些設定會影響事件、心情、金錢壓力與人際關係。

第一版核心循環：

1. 玩家新增或查看居民。
2. 居民依照個性、心情與關係自動產生日常事件。
3. 玩家選擇是否介入，例如送食物、送禮、安排聊天、安撫煩惱。
4. 系統更新居民心情、關係值、社區活躍度與事件紀錄。
5. 玩家持續經營，讓社區累積更多居民故事。

## 開發原則

- 先做可玩的生活模擬循環，再增加內容量。
- 每個居民都需要有個性、需求、心情與關係。
- 關係系統要貼近現實生活，包含友情、曖昧、交往、前任、三角關係、第三者與多人追求等 drama。
- 事件要能由系統組合產生，不只寫死固定劇情。
- 玩家介入應帶來清楚回饋，但不需要傳統勝敗。
- 操作模式以手機橫向觸控可用為硬條件，桌面滑鼠與鍵盤作為補充。
- MVP 美術風格採用像素風。
- 所有素材、命名、角色與世界觀都必須原創。

## 操作模式

本遊戲雖然是 Web 遊戲，但需要能在手機瀏覽器舒適操作。MVP 採用手機橫向優先的點選式互動：

- 單指點選居民、建築、事件與選項。
- 橫向手機以左側或右側固定導覽切換社區、居民、事件、物品與設定。
- 彈出面板顯示居民詳情與事件選項。
- 不依賴滑鼠 hover。
- 不要求精準拖曳或快速反應。
- 桌面版支援滑鼠點選與基本鍵盤導覽。

## MVP 定義

第一版應至少包含：

- 原創社區主畫面。
- 3 至 5 位可建立或預設的居民。
- 居民資料：姓名、外觀代號、個性、人生背景、住處、心情、飢餓或需求、關係。
- 至少 8 種日常事件。
- 玩家可執行至少 3 種介入行動。
- 本機存檔與重新載入。
- 手機瀏覽器可完整操作，桌面瀏覽器也可操作。

## 開發指令

```bash
npm install
npm run dev
npm run build
```

本機開發伺服器預設使用 Vite。手機測試時請使用橫向畫面。
